# Pastella — мебельный магазин (демо-сайт)

Одностраничный сайт мебельного магазина в пастельной палитре с акцентом на анимации и микро-взаимодействия.

## Запуск

```bash
cd furniture-store
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Стек

- Чистый HTML5 + CSS3 + ванильный JavaScript (без сборщиков и фреймворков)
- Шрифты: Cormorant Garamond (заголовки) + Manrope (текст) с Google Fonts
- Изображения сгенерированы в `assets/images/`

## Палитра

- Crema (#FAF7F2, #F5EFE6, #EFE3D0)
- Blush (#F4D0CB, #E5B5AE)
- Sage (#C8D5BB, #A8B89A)
- Clay (#A6907A, #6B5D54)
- Brass-акцент (#C9A47A)

## Что внутри

- Прелоадер с реверс-анимацией шкалы
- Кастомный курсор с эффектом `grow` на интерактивных элементах (десктоп)
- Прозрачный → залитый хедер при скролле
- Hero с параллакс-фоном, blob-формами и поэтапным появлением слов
- Бегущая строка преимуществ
- Сетка коллекций с разными размерами карточек и плавной заменой акцентов
- Каталог с фильтрами по категориям и hover-кнопкой «В корзину»
- Раздел «О бренде» с плавающими изображениями, круглым стикером и счётчиками
- Карточки преимуществ с трансформацией иконки на hover
- Карусель отзывов с автопрокруткой и точками
- Newsletter-блок с плавающими градиентными формами и валидацией
- Тёмный футер с социальными иконками
- Кнопка «Наверх», `prefers-reduced-motion` поддержка

## Адаптивность

- ≥1100 px — десктоп (6-колоночная сетка коллекций, 3 продукта в ряду)
- 860–1100 px — планшет (4 колонки, 2 продукта в ряду)
- ≤860 px — мобайл (бургер-меню, 1 продукт в ряду на ≤600 px)
